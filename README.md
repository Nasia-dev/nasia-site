## project Overview
Na.sia is a personal technology portfolio project created while learning web development and cybersecurity fundamentals. The goal of the site is to document my learning journey while building a professional online presence, that will eventually include projects and research. This site represents the beginning of my work and learning experience in technology and will evolve more as I keep building.

## Technologies Used
### HTML5
Used to structure the webpage and organize the content with semantic element such as; "<sections>", "<header>", "<footer>" and "<nav>"(navigation).
### CSS3
Used to design the visual appearance of the site including layout colors, animation, font and styling rules.
### CSS3 Grid
used to create a responsive layout that automatically adjusts to screen size.
###CSS3 variables(:root)
used to maintain a consistant theme and colors and to simplify any future designs to the site.
### Git
used for version control to track projects and changes.
### GitHubpages
used to deploy to deploy the website live directly from the respitory
